# Teaching · 教学资料

课程讲义与课件仓库，持续更新。

- 在线访问：https://brook5.github.io/teaching/
- 本地预览：直接用浏览器打开 `index.html`

## 目录结构

```
teaching/
├── index.html              # 课程主页
├── README.md
└── database/               # 数据库系统课程
    ├── ch09/               # 第九章 关系系统及其查询优化
    │   ├── index.html      # 网页版课件
    │   └── slides.pdf      # PDF 版课件
    └── ch10/               # 第十章 数据库恢复技术
        ├── index.html
        └── slides.pdf
```

## 新增章节

1. 在对应课程目录下新建章节文件夹（如 `database/ch11/`），放入 `index.html`（网页版）和 `slides.pdf`（PDF 版）；
2. 在根目录 `index.html` 的课程列表中添加该章节的卡片；
3. 提交并推送到 GitHub，GitHub Pages 会自动更新。
